# Funerales González — sitio web

Sitio de [Funerales González](https://www.funeralesgonzalez.com/) construido con Astro y Tailwind CSS.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # genera ./dist
```

Contexto del proyecto, convenciones y pendientes: ver [AGENTS.md](AGENTS.md) (CLAUDE.md apunta a él).
